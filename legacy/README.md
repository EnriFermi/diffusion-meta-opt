# Legacy

This directory contains code and launchers that are not part of the active
BigVAE training/evaluation path.

Kept here:

- `mini_vae/`: old MiniVAE training and pretraining entrypoints.
- `mini_vae_pipeline/`: old MiniVAE pipeline package.
- `procedural_simple_vae_pipeline/`: old procedural/simple VAE experiments.
- `quarantine/`: files removed from the active tree but preserved with their
  original relative paths.
- `adhocs/`, `tutorials/`, `analysis/`, `toys/`: notebooks, one-off analyses,
  and old scripts.

Active BigVAE code stays in `big_vae`, `training/big_vae`,
`dataset/big_vae_offline_parts`, `post_train_research`, and
`scripts/launchers/{big_vae,post_train}`.
