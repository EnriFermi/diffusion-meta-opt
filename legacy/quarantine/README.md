# Legacy Quarantine

Files in this directory were removed from the active import/launch/config tree
but are intentionally preserved here.

The path under `legacy/quarantine/` mirrors the old repository-relative path.
For example, `legacy/quarantine/models/simple_big_weight_vae.py` used to live at
`models/simple_big_weight_vae.py`.

Active BigVAE code must not import from this directory.
